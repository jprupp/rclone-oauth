Privacy policy

rclone personal OAuth client. Last updated: 8 November 2026

Summary

This OAuth client is used only by its owner, JP Rupp, with rclone to access their own Google Drive. It collects no data, stores no data on any server, and shares no data with anyone.

Data accessed

When the owner authorizes rclone, Google gives rclone access to the owner's Google Drive files and file metadata. rclone uses this access only to carry out file operations the owner runs on their own computers.

Storage

The OAuth token lives only in the owner's local rclone configuration file (rclone.conf). File contents move directly between Google Drive and the owner's devices. Nothing passes through, or is kept on, any server run by this client's owner.

Sharing

No data is sold, shared, transferred or used for advertising, analytics or model training.

Google API Services User Data Policy

This client's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the remote from rclone.conf removes the local token.
